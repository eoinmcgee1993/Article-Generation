# Substack Content OS

AI-native Substack publishing control plane. Phase 1 foundation: dashboard shell, MCP-ready domain model, publishing queue, voice/analytics abstractions, and deployment scaffolding.

## Phase 1
- Dashboard shell
- Content queue
- Publishing calendar
- Approval gates
- Voice profile model
- Analytics model
- Adapter interface for Substack
- MCP server contract

## Run
npm install
npm run dev
